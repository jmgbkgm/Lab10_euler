# Техническое задание на разработку ИС "Векторный анализ"

## 1. Общие сведения
Разработка консольного приложения на Python для сложения \(N\)-мерных векторов и вычисления их длины.

## 2. Требования к программе
- Ввод векторов через консоль (через запятую) или загрузка из JSON.
- Вычисление суммы двух векторов.
- Вычисление длины (модуля) результирующего вектора.
- Сохранение результатов в JSON-файл.
- Восстановление данных из JSON-файла.

## 3. Требования к документации
- Руководство пользователя на русском и английском языках.
- Регламент технического обслуживания.
- Тест-кейсы (Unit-тесты).

```markdown
# Руководство пользователя (Векторный анализ)

## Установка
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите программу: `python main.py --help`

## Использование
### Сложение векторов
`python main.py --action calc --v1 "1,2,3" --v2 "4,5,6"`
Вывод: `Результат сложения: [5.0, 7.0, 9.0]`, `Длина: 12.4499`

### Сохранение в файл
Добавьте флаг `--file data.json` к команде выше.

### Загрузка из файла
`python main.py --action load --file data.json`
```
