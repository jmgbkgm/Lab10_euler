# Проект: Сложение векторов в N-мерном пространстве

## 🇷🇺 Русский

### 🎯 Цель работы
Разработка консольной программы на языке Python для выполнения математических операций над векторами в N-мерном пространстве, а также освоение навыков работы с файловым вводом/выводом, написания тестов и подготовки пользовательской документации.

### 📋 Описание проекта
Программа предназначена для сложения двух векторов, заданных пользователем, и вычисления параметров результирующего вектора. 
Проект включает в себя:
- Интерактивный ввод координат векторов через консоль.
- Возможность чтения исходных данных из файла (JSON) и записи результата в файл.
- Вычисление координат суммы двух векторов.
- Вычисление длины (модуля) получившегося вектора.
- Валидацию данных (проверка на то, что векторы имеют одинаковую размерность).
- Модуль резервного копирования пространственных данных геометрии.
