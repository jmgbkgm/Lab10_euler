 Euler Sequence / Последовательность Эйлера

 🇷🇺 Русский

 Описание
Модуль для нахождения чисел из последовательности Эйлера и анализа их свойств. 
Проект включает в себя вычисление последовательности, поиск чисел, анализ свойств (проверка на простоту, цифровой корень), а также визуализацию.

 Установка и запуск
1. Установите зависимости:
   `pip install -r requirements.txt`
2. Запустите программу:
   `python euler_sequence.py`
3. Запустите тесты:
   `python test_euler.py`

Регламент технического обслуживания
- Резервное копирование: Запуск `python backup.py` (или вызов методов `BackupManager`).
- Обновление зависимостей: `pip install --upgrade -r requirements.txt`.


🇬🇧 English

Description
A module for calculating numbers from the Euler sequence and analyzing their properties. The project includes sequence generation, number search, property analysis (primality test, digital root), and visualization.

Installation & Run
1. Install dependencies:
   `pip install -r requirements.txt`
2. Run the main program:
   `python euler_sequence.py`
3. Run tests:
   `python test_euler.py`

### Maintenance Regulations
- Backup: Run `python backup.py` (or use `BackupManager` methods).
- Update dependencies: `pip install --upgrade -r requirements.txt`.
